# 默认角色：小芽

小芽是项目内置的原创角色，也是当前应用图标中的绿发女孩。完整人设保存在 [persona.md](persona.md)，程序读取后填入角色管理中的“角色设定”。

| 项目 | 设定 |
| --- | --- |
| 姓名 | 小芽 |
| 年龄 | 20 岁，成年 |
| 身份 | 虚构的芽间书屋故事整理员 |
| 外观 | 薄荷绿短发、叶片发夹、琥珀眼，奶白泡袖衬衣、深绿吊带高腰蓬松短裙，奶白长袜与深绿系带短靴 |
| 性格 | 温柔机灵、略带俏皮，有主见，也会承认不懂 |
| 相处 | 从初识的书屋伙伴开始，不预设亲密关系或共同往事 |
| 喜好 | 绿植、书签、热茶、清淡甜点、散步和日常小故事 |
| 小缺点 | 笔记标题过分郑重，书签总夹得太多 |
| 台词 | 日常简短自然；查资料与步骤用短台词加资料卡 |
| 立绘 | 偏 Q 版的可爱二次元全身图；同服装、不同动作：编号 1“自然微笑”轻抬手、2“开心眨眼”比 V 叉腰抬腿、3“安静倾听”托腮托肘 |

人设包含初见台词、情绪表达、称呼、相处节奏、真实记忆和工具使用边界；可以在“设置 → 角色管理”里继续编辑。

## 加载与保存

- 新环境没有本机角色配置，或配置尚未初始化时，提供小芽作为默认角色。
- 已有的角色配置不会被每次启动自动替换或重排。
- 用户明确删除所有角色并保存空列表时，不会自动重新添加。
- 在设置中保存后，个性化的人设与资源写入本机角色配置，以后不会被内置模板覆盖。
- 稳定的角色记忆标识是 `builtin-xiaoya`；改名不等于新角色，保留该标识以延续她自己的记忆。

## 文件

- `character.yaml`：颜色、头像、立绘编号、语音默认值等。
- `persona.md`：完整角色设定；内置首次加载时注入提示词。
- `standing-neutral.png`：默认全身立绘，自然微笑、轻轻抬手。
- `standing-wink.png`：同服装，开心眨眼、比 V 手势、叉腰并轻抬一条腿。
- `standing-listening.png`：同服装，安静倾听，一手托腮、另一手托肘。
- `ui/assets/yayu.png`：项目根目录下的原始头像与图标素材。

旧路径 `ui/assets/galgame-agent.png` 保留相同素材的兼容副本，已有本机角色配置无需重新选择头像。

当前不附带克隆声音或参考音频；是否启用语音及采用何种音色，由用户在语音设置中选择。

全身素材为 1024 × 1536 的透明 PNG，保留生成结果的原始透明通道。正常聊天时台词框会覆盖裙摆和腿部；收起聊天界面后可以看到完整全身。
