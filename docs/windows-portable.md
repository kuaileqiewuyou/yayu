# 芽语 Windows 便携版

从 [GitHub Releases](https://github.com/kuaileqiewuyou/yayu/releases/latest) 下载 Windows 便携 ZIP，完整解压到有写入权限的文件夹。

1. 双击 **Yayu Settings.exe**，在“模型配置”选择服务；其他 OpenAI 兼容服务请选择“自定义”，填写自己的 Base URL、API Key 和模型 ID，然后保存并关闭设置。
2. 双击 **Yayu.exe** 打开聊天。默认角色是带完整人设和三张全身立绘的小芽。
3. 多角色时，点击台词框左上角的角色名选择；也可从主界面打开设置，在角色卡片上点击“使用此角色”。立绘与角色设定同步切换，每个角色使用自己的聊天记录和记忆，切回来继续最近的会话。回复中请先点“停止”。单独运行设置 EXE 时，角色选择在下次打开主界面生效。

便携包自带 Python 和应用依赖，不需要安装 Python、创建 venv 或运行 pip。两个 EXE 与 `runtime/`、应用文件及 `data/` 必须一起保留；不要只复制 EXE，也不要在 ZIP 内直接双击运行。

支持 Windows 10 1809 及以上 / Windows 11 x64，平台范围以 [Qt 6.8 官方说明](https://doc.qt.io/qt-6.8/supported-platforms.html) 为准。当前未在全新虚拟机上验证系统兼容性。

## 配置与个人数据

发布包只包含空白的通用 API 默认值、公用配置示例和内置小芽，不含开发者的密钥、私人角色、导入图片、聊天、记忆、安全授权或日志。首次启动才在解压目录创建本人的配置和数据。

- `data/config/api.local.yaml`：保存你自己填入的 API Key 和接口设置。
- `data/chat_history/`：保存你自己的会话和记忆数据。
- `data/appdata/`：便携版单独使用的本机权限与授权数据。
- `logs/`：两个 EXE 的启动及错误日志。

初始化只补全缺失文件，不覆盖已有设置或清空聊天。更新前备份整个 `data/`；不要将填写过密钥或聊过天的文件夹直接转发他人。用于分享时重新下载原始 ZIP。

首次默认角色使用项目相对资源路径，可随整个文件夹移动；你自己填写的绝对外部文件路径仍需自行维护。

## 检查与安装更新

1. 打开“设置 → 系统设置 → 软件更新”，点击“检查更新”。
2. 有新版时，点击“更新到 …”。确认后下载并校验发布包；准备完成后保存尚未保存的设置，正常关闭当前芽语窗口。
3. 独立更新程序等待主界面、设置窗口及其启动器全部退出，备份完整个人数据和旧程序，再在**原安装路径**替换程序并自动重启。请先关闭另外单独运行的芽语窗口，以免更新一直等待。

已有 `data/` 文件不会被发行包的默认值覆盖，角色身份、配置、立绘、背景、聊天和 SQLite 记忆保留。新版内置公开资源仅补充缺失文件；你放在程序目录外的图片、音频仍使用原路径。程序目录中不属于发行清单的文件也保留；若自定义文件与新版冲突，或向 `runtime/` 手工安装过额外依赖，程序会停止更新并提示处理，不会直接删除这些文件。

备份保存在安装目录旁的 `.yayu-updates/<更新编号>/backup/`，里面包含私人配置和聊天，仅留在本机，勿作为安装包分享。更新失败会尝试恢复旧程序；新版须打开主窗口并通过启动检查才算成功。更新中断后，再次双击原目录的 EXE 会尝试恢复；若仍有窗口或文件被占用，先关闭它们再重试，保留备份目录。

更新只读取固定 GitHub 仓库的正式 Release，不上传角色、密钥、配置或聊天。仓库为私有时，可沿用已安装 GitHub CLI 的登录，或在“GitHub 访问设置”保存有该仓库 **Contents: Read** 权限的访问令牌；令牌经 Windows 当前账户加密，仅在本机使用。更换电脑或 Windows 账户后可能需要重新授权。

不会在启动时自动检查或强制更新；下载阶段可以取消，安装阶段由独立程序完成。源码运行可检查版本，自动安装仅供带完整发行清单的 Windows 便携版使用。

此入口从 1.0.4 起提供。1.0.3 及更早版本需先升级一次：关闭程序、备份旧目录，将新版除 `data/` 外的程序文件和完整 `runtime/` 更新回原路径；后续即可使用内置更新。

## 功能边界

程序可以直接打开设置和聊天界面；生成回复需要配置可访问的模型服务。Edge TTS 和原生 Claude 的客户端依赖已随包提供，但服务本身仍需要网络或你的密钥。

GPT-SoVITS、ComfyUI 模型与服务器、MCP 外部命令服务不在包内。ASR 麦克风识别尚未接入主界面。终端默认使用系统环境；Git、bash、Node/npx、winpty 等工具没有随便携包附带，相关功能需自行安装。

## 校验与排错

可用 PowerShell 检查下载文件的 SHA256，与 Release 中的 `SHA256SUMS.txt` 对比：

```powershell
Get-FileHash .\Yayu-1.0.5-windows-x64.zip -Algorithm SHA256
```

启动失败时先确认已完整解压，且当前目录可写，再查看 `logs/` 中最新的 `chat-*.log` 或 `settings-*.log`。发行包未进行代码签名；Windows 可能显示来源或签名提示，请核对下载来源和校验值。

`BUILD_INFO.json` 记录源码提交、Python 版本及第三方 wheel 哈希；`PACKAGE_MANIFEST.json` 记录初始文件清单和哈希。

## 从源码重建

Windows x64、Python 3.13、Git 和 .NET Framework C# 编译器可用后执行：

```powershell
python scripts\build_windows_portable.py --ref HEAD --work-dir .sandbox\portable-build --output-dir .sandbox\releases
```

构建器只读取指定的 Git 提交，按白名单抽取应用代码和公开资源，从 Python 官方下载并验证嵌入式运行时 SHA256，再从 PyPI 下载独立依赖；不会复制当前 venv、工作目录的私人配置或聊天。已有构建目录和发行 ZIP 不会被覆盖，请为新构建选择新目录。
