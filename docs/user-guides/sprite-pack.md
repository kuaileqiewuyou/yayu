# 角色立绘包

在「设置 → 角色管理」打开角色详情，可以继续批量导入立绘包，也可以在情绪行中单独导入图片。

- 选中一张立绘，点击「放大预览」，或直接双击列表项。
- 预览窗口支持滚轮或按钮缩放、拖动查看、适应窗口和原始大小。
- 点击「删除选中立绘」可移除该项，相关情绪会解除绑定，可重新选择图片；剩余立绘编号不变。
- 点击「保存配置」后删除操作持久化，项目 `data/sprites` 下不再被使用的对应图片会被清理。外部原始导入文件，以及其他角色、情绪或头像仍在使用的图片都会保留。
- 保存失败时保留图片和待删除记录，可以修正问题后重新保存。替换情绪绑定不会自动删除立绘包里的旧图，需要在包中手动删除。

旧配置中，情绪可能指向原始导入文件而立绘包指向归档副本。删除时会核对文件名与内容，兼容这种旧绑定；新导入图片保存后会将绑定路径同步到归档副本。
