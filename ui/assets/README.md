# Yayu application icon

`yayu.png` is the original anime mascot artwork, generated with the
built-in imagegen tool and selected by the user on 2026-10-20. The mascot has
sage-green hair, an ivory leaf hair clip, and a winking smile.
`yayu.ico` contains 16, 20, 24, 32, 40, 48, 64, 96, 128 and 256 pixel
PNG frames with transparency. Both Windows launchers, the Qt application and
window icons, and the settings title bar use this same artwork. It is
independent of the character avatars and sprite files. The original
`galgame-agent.png` / `galgame-agent.ico` paths are retained as identical
compatibility copies for older launchers and local resource references.

To rebuild from the project root:

```powershell
./venv/Scripts/python.exe scripts/build_launcher_icon.py
./scripts/build_windows_launcher.ps1
```

## Generation prompt

Create one polished original anime chibi mascot icon for a cozy desktop visual-novel chat app. A brand new character designed from scratch, no existing franchise or known character. Single large expressive head, nearly filling the square canvas, with only a tiny hint of shoulders. A cheerful little anime girl with a distinctive rounded sage-green bob haircut, one playful curled hair tuft, an ivory leaf-shaped hair clip, warm amber eyes, softly blushing cheeks, and an unmistakable playful smug smile: one eye winking, the other a large friendly golden eye, tiny catlike smiling mouth. A lively reaction-sticker / anime emote feeling, cute and confident, not a detailed portrait. Make the face very large and readable, with simplified chunky hair shapes and clean dark forest-green outlines. Flat cel shading, soft mint and ivory palette with small warm peach accents. Strong outer silhouette with a narrow ivory sticker border and forest-green keyline. Clean professional desktop app mascot, crisp enough to recognize at 24 and 32 pixels. No hands, no floating decorations, no speech bubbles, no words, no lettering, no watermark, no multiple panels, no mockup, no realistic rendering. Centered composition. True transparent background outside the character silhouette. Output a square high-resolution PNG icon concept.
